# 单个模型详细对比图表

本目录包含每个模型单独的详细分析图表，用于补充主论文中的综合对比图。

## 图表列表

### 1. all_models_individual_mae.png/pdf
- **内容**: 2×2子图，每个子图展示一个模型的Baseline vs MIM的MAE曲线
- **用途**: 便于读者聚焦单个模型的详细表现
- **适用章节**: 实验结果分析

### 2. all_models_individual_improvement.png/pdf
- **内容**: 2×2子图，每个子图展示一个模型的MIM改进率柱状图
- **用途**: 直观显示每个模型在不同缺失率下的改进幅度
- **适用章节**: MIM改进率分析

### 3. high_missing_rate_detail.png/pdf
- **内容**: 高缺失率区域(0.6-0.9)的详细对比柱状图
- **用途**: 突出展示高缺失率下各模型的性能差异
- **适用章节**: 高缺失率鲁棒性分析

### 4. all_models_individual_r2.png/pdf
- **内容**: 2×2子图，每个子图展示一个模型的Baseline vs MIM的R²曲线
- **用途**: 展示模型解释力的变化，特别是基线模型失效情况
- **适用章节**: 模型鲁棒性分析

## 使用建议

这些图表可作为补充材料，或在正文中选择性使用以增强论文的完整性。
