# 分层实验架构设计文档

## 1. 架构概述

实验采用**分层控制变量架构**，通过 Hydra + PyTorch Lightning 实现：

```
Full Experiment Grid (完整实验网格)
├── Dataset Loop (4 datasets: XJTU, TJU, HUST, MIT)
│   ├── Missing Mechanism Loop (2 modes: MCAR, MAR)
│   │   ├── Method Loop (5 methods: MIM, Mean, Median, KNN, Zero)
│   │   │   ├── Model Loop (4 models: MLP, LSTM, GRU, CNN1D)
│   │   │   │   └── Seed Loop (100 seeds: 42-141)
│   │   │   │       └── Missing Rate Evaluation (9 rates: 0.1-0.9)
```

**总实验数**: 4 × 2 × 5 × 4 × 100 × 9 = **144,000 次评估**

## 2. 实验层级定义

### 2.1 单次实验 (Single Experiment)

**定义**: 固定 (dataset, mode, method, model, seed) 的一次完整实验

**等价命令**:
```bash
python src/main.py \
    data=xjtu \
    missing=mcar \
    method=mim \
    model=mlp \
    experiment.seeds=[42] \
    training.epochs=100
```

**职责**:
- 加载指定数据集，按电池划分 train/val/test
- 根据 method 确定训练策略:
  - **MIM**: 混合缺失率 0.0-0.9 训练
  - **Mean/Median/KNN/Zero**: 完整数据训练
- 训练模型，早停监控
- 在 9 个缺失率下评估 (0.1, 0.2, ..., 0.9)
- 保存结果到 CSV

**输出**:
```
results/battery_soh_experiment_mlp_mim.csv
├── seed=42, MR=0.1, MAE=0.0104, RMSE=0.0132, R²=0.9989
├── seed=42, MR=0.2, MAE=0.0107, RMSE=0.0135, R²=0.9988
├── ...
└── seed=42, MR=0.9, MAE=0.0253, RMSE=0.0318, R²=0.9941
```

### 2.2 批量实验 (Batch Experiment)

**定义**: 多个单次实验的组合，通过脚本自动化执行

**场景1: 种子重复** (统计显著性)
```bash
python src/main.py \
    data=xjtu model=mlp method=mim \
    experiment.seeds=[42,43,44,...,141] \
    training.epochs=100
```

**场景2: 方法对比** (MIM vs Baselines)
```bash
for method in mim mean median knn zero; do
    python src/main.py \
        data=xjtu model=mlp method=$method \
        experiment.seeds=[42,43,44] \
        training.epochs=100
done
```

**场景3: 全网格扫描** (完整论文实验)
```bash
./scripts/run_full_experiment.sh
```

## 3. 核心设计决策

### 3.1 为什么分层？

| 优势 | 说明 |
|------|------|
| **容错** | 单次实验失败不影响其他组合，可单独重跑 |
| **并行** | 不同组合可在多 GPU/多节点上并行执行 |
| **增量** | 可逐步扩展实验规模，先跑小网格验证 |
| **调试** | 可固定其他维度，单独调试某一维度 |

### 3.2 控制变量原则

每次只改变一个维度，其他保持固定：

```python
# 比较不同模型 (固定 dataset, mode, method, seed)
for model in [mlp, lstm, gru, cnn1d]:
    run_experiment(data=xjtu, missing=mcar, method=mim, model=model, seed=42)

# 比较不同方法 (固定 dataset, mode, model, seed)
for method in [mim, mean, knn]:
    run_experiment(data=xjtu, missing=mcar, method=method, model=mlp, seed=42)
```

### 3.3 结果聚合

**跨种子聚合** (同一配置，不同随机性):
```python
# 计算 100 个种子的均值和标准差
mae_mean = results.groupby('missing_rate')['test_mae'].mean()
mae_std = results.groupby('missing_rate')['test_mae'].std()
```

**跨方法聚合** (同模型，不同缺失处理):
```python
# 比较 MIM vs Mean 在所有缺失率下的表现
for mr in [0.1, 0.2, ..., 0.9]:
    mim_mae = mim_results[mim_results.missing_rate==mr].test_mae
    mean_mae = mean_results[mean_results.missing_rate==mr].test_mae
    t_stat, p_value = ttest_ind(mim_mae, mean_mae)
```

## 4. 训练策略详解

### 4.1 MIM 方法

```
输入: 完整训练集 X_train [N, 16], y_train [N]
处理:
  1. 生成 10 个缺失率版本:
     - copy_0: MR=0.0 (完整)
     - copy_1: MR=0.1
     - ...
     - copy_9: MR=0.9
  2. 每份生成 MIM 格式: [X_imputed, mask] → [N, 32]
  3. 合并: [10*N, 32]
训练: 在合并数据上训练单个模型
测试: 对指定 MR 生成 MIM 输入，评估
```

### 4.2 插补 Baselines

```
输入: 完整训练集 X_train [N, 16], y_train [N]
处理: 无缺失处理，直接训练
训练: 在完整数据上训练
测试:
  1. 对指定 MR 生成缺失数据
  2. 用对应方法插补 (Mean/Median/KNN/Zero)
  3. 评估
```

import pandas as pd

mim = pd.read_csv('results/battery_soh_xjtu_mlp_mim.csv')

### 7.2 跨种子统计

# 按缺失率分组，计算均值和标准差
mim_stats = mim.groupby('missing_rate')['test_mae'].agg(['mean', 'std'])

### 7.3 显著性检验
```python
from scipy.stats import ttest_ind

for mr in [0.1, 0.3, 0.5, 0.7, 0.9]:
    mim_mae = mim[mim.missing_rate==mr].test_mae
    mean_mae = mean[mean.missing_rate==mr].test_mae
    t, p = ttest_ind(mim_mae, mean_mae)
    print(f"MR={mr}: p={p:.4f} {'***' if p<0.001 else '**' if p<0.01 else '*' if p<0.05 else ''}")
```

## 8. 故障排查

### 8.1 实验中断
- **原因**: 系统崩溃、OOM、手动终止
- **解决**: 重新运行相同命令，已完成的种子会自动跳过 (基于 CSV 文件存在性检查)

### 8.2 结果不一致
- **检查**: 确认 `random_state` 一致
- **验证**: 固定种子重跑，比较两次结果

### 8.3 内存不足
- **原因**: MIM 训练集扩大 10 倍
- **解决**: 减小 `training.batch_size` (64→32→16)
