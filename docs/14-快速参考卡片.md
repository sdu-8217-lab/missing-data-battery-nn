# 快速参考

## 启动实验

```bash
# 完整大实验（100次重复）
python run_batch.py --batch 3C --n_repeats 100 --epochs 50

# 小实验（单次，用于调试）
python run_single.py --batch 3C --seed 42 --epochs 50

# 中断恢复
python run_batch.py --batch 3C --n_repeats 100 --epochs 50 --resume
```

## 检查状态

```bash
# 查看实验进度
python check_status.py --experiment_dir experiments/3C/20240203_120000
```

## 绘图

```bash
# 大实验统计图（所有种子）
python plot_batch.py --input experiments/3C/20240203_120000

# 单个小实验图
python plot_single.py --input experiments/3C/20240203_120000/seed_42/results.csv
```

## 目录结构

```
experiments/3C/20240203_120000/
├── checkpoint.json          # 检查点（用于恢复）
├── seed_42/                 # 小实验结果
│   ├── results.csv         # 数据
│   ├── figures/            # 5张图表
│   └── models/             # 10个模型
├── seed_43/
├── ...
└── aggregate/               # 统计结果
    ├── results_all.csv     # 所有数据合并
    └── figures/            # 6张统计图
```

## 常见问题

**Q: 如何恢复中断的实验？**
```bash
python run_batch.py --batch 3C --n_repeats 100 --resume
```

**Q: 如何只运行特定种子？**
```bash
python run_single.py --seed 100 --epochs 50
```

**Q: 实验中断后如何手动绘图？**
```bash
python plot_batch.py --input experiments/3C/20240203_120000
```
