## 2. 模型架构与目标参数量

### 2.1 MLP (Multilayer Perceptron)

**架构**: Input → 192 → 96 → 48 → 24 → 1

| 组件 | 配置 |
|------|------|
| 隐藏层 | [192, 96, 48, 24] |
| 激活函数 | ReLU |
| Dropout | 0.15 |
| 输出 | 1 (SOH预测值) |

**参数量计算公式**:
```
Params = (input_dim × 192 + 192) + (192 × 96 + 96) + (96 × 48 + 48) + (48 × 24 + 24) + (24 × 1 + 1)
```

| 策略 | 输入维度 | 目标参数量 | 状态 |
|------|---------|-----------|------|
| Baseline | 16 | **27,649** | 待验证 |
| MIM | 32 | **36,865** | 待验证 |

**计算验证 (Baseline)**:
- Layer 1: (16 × 192) + 192 = 3,072 + 192 = 3,264
- Layer 2: (192 × 96) + 96 = 18,432 + 96 = 18,528
- Layer 3: (96 × 48) + 48 = 4,608 + 48 = 4,656
- Layer 4: (48 × 24) + 24 = 1,152 + 24 = 1,176
- Output: (24 × 1) + 1 = 24 + 1 = 25
- **总计**: 3,264 + 18,528 + 4,656 + 1,176 + 25 = **27,649** ✓

**计算验证 (MIM)**:
- Layer 1: (32 × 192) + 192 = 6,144 + 192 = 6,336
- Layer 2-4 + Output: 同上 = 24,385
- **总计**: 6,336 + 24,385 = **30,721** ✗ **与论文 36,865 不符！**

> **⚠️ 发现问题**: 当前计算与论文目标值存在差异，需在 Task 1.2 中修正

### 2.2 LSTM (Long Short-Term Memory)

**架构**: 2-layer LSTM → FC

| 组件 | 配置 |
|------|------|
| LSTM层数 | 2 |
| 隐藏维度 | 48 |
| 序列长度 | 5 |
| Dropout | 0.2 |
| 输出 | 1 (SOH预测值) |

| 策略 | 输入维度 | 目标参数量 | 状态 |
|------|---------|-----------|------|
| Baseline | 16 | **31,537** | 待验证 |
| MIM | 32 | **40,753** | 待验证 |

**参数量估算** (PyTorch LSTM):
- LSTM参数 = 4 × (input_dim × hidden_dim + hidden_dim² + hidden_dim) 每方向每层
- 2层双向: 2 × 4 × (16 × 48 + 48² + 48) ≈ 2 × 4 × (768 + 2,304 + 48) = 2 × 4 × 3,120 = 24,960
- FC层: 48 × 1 + 1 = 49
- **估算总值**: ~25,009 (与目标 31,537 有差异，需进一步验证)

## 7. 关键发现与问题

### 7.1 当前实现与论文差异

**MLP 差异分析**:
- 论文 MIM 目标: 36,865
- 当前计算值: 30,721
- 差异: -6,144 参数

**可能原因**:
1. 当前隐藏层维度与论文不一致
2. 论文中 MLP 可能有额外的层或连接
3. 需要调整架构以匹配目标参数量
