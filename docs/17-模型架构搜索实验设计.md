# 模型架构搜索实验设计

## 1. 实验目标

在给定参数范围内，寻找每个模型（MLP/LSTM/GRU/CNN1D/XGBoost）的最佳架构平衡点：
- **性能维度**：MAE、RMSE、R²
- **复杂度维度**：参数量、训练时间、推理时间
- **平衡点**：在可接受复杂度下的最佳性能

## 2. 搜索空间定义

### 2.1 MLP

| 参数 | 搜索范围 | 说明 |
|------|----------|------|
| `hidden_layers` | [[64], [128], [256], [64,32], [128,64], [256,128], [128,64,32], [256,128,64]] | 层数和宽度组合 |
| `dropout` | [0.0, 0.2, 0.5] | 正则化强度 |

**理论参数量估算**：
- 输入16维，输出1维
- [256,128,64]: 16×256 + 256×128 + 128×64 + 64×1 ≈ **50K**
- [64,32]: 16×64 + 64×32 + 32×1 ≈ **3K**

### 2.2 LSTM/GRU

| 参数 | 搜索范围 | 说明 |
|------|----------|------|
| `hidden_size` | [16, 32, 64, 128] | 隐藏层维度 |
| `num_layers` | [1, 2, 3] | 堆叠层数 |
| `dropout` | [0.0, 0.2, 0.5] | 正则化 |

**理论参数量估算**（LSTM，输入16，序列5）：
- hidden=64, layers=1: ~**20K**
- hidden=128, layers=2: ~**150K**

### 2.3 CNN1D

### 2.4 XGBoost

## 3. 分层迭代策略（Coarse-to-Fine）

### 阶段1：粗粒度筛选（Coarse Search）

**目标**：快速排除明显不好的架构

**配置**：
- 每个模型：8-12 个代表性架构
- 训练：10 epochs（快速收敛判断）
- 缺失率：只测试 0.5（中等缺失）
- 重复：1 个种子

**筛选标准**：
- MAE > 基线 × 1.5 → 淘汰
- 参数量 > 100K 且性能无优势 → 淘汰

### 阶段2：细粒度验证（Fine Search）

**目标**：在候选架构中精确比较

**配置**：
- 从阶段1筛选出 top 3-5 个架构
- 训练：50 epochs（完整训练）
- 缺失率：0.1, 0.5, 0.9（低中高）
- 重复：3 个种子（稳定性验证）

### 阶段3：帕累托最优分析（Pareto Analysis）

**目标**：找到性能-复杂度的最佳平衡点

**分析内容**：
- 绘制 参数量 vs MAE 散点图
- 标记帕累托前沿（Pareto Frontier）
- 计算性价比指标：性能提升 / 参数量增加

## 4. 实验剪枝策略（Early Stopping）

### 4.1 训练早停
```python
# 如果验证损失连续5轮不下降，提前终止
patience = 5
min_delta = 0.001
```

### 4.2 架构剪枝
```python
# 阶段1中动态剪枝规则
def should_prune(current_mae, baseline_mae, epoch, max_epochs):
    # 如果当前MAE比基线差很多，且已过30%训练，剪枝
    if current_mae > baseline_mae * 1.5 and epoch > max_epochs * 0.3:
        return True
    # 如果参数量>100K但MAE>0.1，剪枝
    if params > 100000 and current_mae > 0.1:
        return True
    return False
```

## 5. 评估指标

### 5.1 性能指标
- `MAE_mean`：多缺失率下的平均MAE
- `MAE_high`：高缺失率（0.9）下的MAE（鲁棒性）
- `R2_mean`：决定系数

### 5.2 效率指标
- `param_count`：参数量
- `training_time`：训练时间（秒）
- `inference_time`：单次推理时间（毫秒）

### 5.3 综合评分（用于排序）
```python
# 综合评分公式
score = (0.4 * normalized_mae + 
         0.3 * normalized_params + 
         0.2 * normalized_training_time +
         0.1 * normalized_inference_time)

# 越低越好
```
