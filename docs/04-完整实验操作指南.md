# 完整实验指南

## 实验概述

- **实验批次**: 3C
- **重复次数**: 100 (种子 42-141)
- **模型配置**: 10种 (5模型 × 2配置)
  - 模型: MLP, LSTM, GRU, CNN1D, XGBoost
  - 配置: Baseline (基线), MIM (缺失值处理)
- **缺失率测试**: 9种 (0.1, 0.2, ..., 0.9)
- **总评估数**: 100 × 10 × 9 = 9000

## 启动完整实验

### 方法1: 批处理文件 (推荐)

双击运行:
```
run_full_100_repeats.bat
```

### 方法2: Python后台运行

```bash
python start_full_experiment.py
```

### 方法3: 直接命令行

```bash
python run_full_experiment.py --batch 3C --n_repeats 100 --epochs 50
```

## 中断与恢复

如果实验中断:
1. 检查已完成的结果
2. 修改 `run_full_experiment.py` 中的种子范围
3. 重新运行

## 故障排除

### 内存不足
- 减少 `batch_size`
- 减少 `n_repeats`

### 运行太慢
- 使用GPU版本PyTorch
- 减少 `epochs` (默认50)

### 编码错误
- 已修复: 所有Unicode字符已替换为ASCII
