# 新架构使用指南

## 快速开始

### 1. 运行完整大实验（100次重复）

```bash
python run_batch.py --batch 3C --n_repeats 100 --epochs 50
```

### 2. 运行单个小实验（调试用）

```bash
python run_single.py --batch 3C --seed 42 --epochs 50
```

### 3. 中断恢复

如果大实验意外中断：

```bash
python run_batch.py --batch 3C --n_repeats 100 --epochs 50 --resume
```

### 4. 检查实验状态

```bash
python check_status.py --experiment_dir experiments/3C/20240203_120000
```

### 5. 手动生成图表

大实验中断后，手动绘制统计图：

```bash
# 绘制统计性图表（基于已完成的结果）
python plot_batch.py --input experiments/3C/20240203_120000

# 或指定输入文件
python plot_batch.py --input experiments/3C/20240203_120000/aggregate/results_all.csv
```

为单个小实验绘图：

```bash
python plot_single.py --input experiments/3C/20240203_120000/seed_42/results.csv
```

## 训练策略

### Baseline模型（不带缺失指示器）

```
输入: 完整训练集
处理: 不处理缺失
训练: 标准训练
评估: 在9种缺失率下测试
```

### MIM模型（带缺失指示器）

```
输入: 完整训练集
处理: 
  1. 复制10份
  2. 分别施加 missing_rate = [0.0, 0.1, ..., 0.9]
  3. 每份拼接缺失指示器 (16+16=32维)
  4. 拼接成10×大小的大训练集
训练: 在大训练集上训练
评估: 在9种缺失率下测试
```

## 容错与恢复

### 自动保存

- 每个小实验完成后立即保存结果
- 每10个种子保存一次聚合结果
- 检查点自动更新

### 手动恢复流程

1. 检查状态：
   ```bash
   python check_status.py --experiment_dir experiments/3C/20240203_120000
   ```

2. 继续运行：
   ```bash
   python run_batch.py --batch 3C --n_repeats 100 --resume
   ```

3. 如只需绘图：
   ```bash
   python plot_batch.py --input experiments/3C/20240203_120000
   ```

## 命令行参数

### run_batch.py

```
--batch              数据批次 (默认: 3C)
--n_repeats          重复次数/种子数 (默认: 100)
--epochs             训练轮数 (默认: 50)
--lr                 学习率 (默认: 0.001)
--batch_size         批次大小 (默认: 32)
--patience           早停耐心值 (默认: 15)
--device             计算设备 (默认: cpu)
--resume             从检查点恢复
```

### run_single.py

```
--batch              数据批次 (默认: 3C)
--seed               随机种子 (默认: 42)
--epochs             训练轮数 (默认: 50)
--lr                 学习率 (默认: 0.001)
--batch_size         批次大小 (默认: 32)
--patience           早停耐心值 (默认: 15)
--device             计算设备 (默认: cpu)
--output             输出目录
```

### plot_batch.py

```
--input              输入目录或CSV文件 (必需)
--output             输出目录 (可选)
```

### plot_single.py

```
--input              结果CSV文件路径 (必需)
--output             输出目录 (可选)
```

## 常见问题

### Q: 实验中断后如何恢复？
A: 使用 `--resume` 参数：
```bash
python run_batch.py --batch 3C --n_repeats 100 --resume
```

### Q: 只想重新生成图表怎么办？
A: 使用独立绘图脚本：
```bash
python plot_batch.py --input experiments/3C/20240203_120000
```

### Q: 如何只运行特定种子？
A: 使用单实验脚本：
```bash
python run_single.py --seed 100 --epochs 50
```

### Q: 如何查看进度？
A: 使用状态检查脚本：
```bash
python check_status.py --experiment_dir experiments/3C/20240203_120000
```

### Q: 实验运行多长时间？
A: 参考时间（CPU）：
- 1个小实验（10模型）: ~5-10分钟
- 100次大实验: ~6-12小时
