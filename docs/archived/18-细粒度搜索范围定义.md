# 细粒度架构搜索 - 宽泛范围定义

## 搜索原则

1. **覆盖甜点区**：确保包含初步实验发现的最佳配置
2. **向两侧扩展**：向小参数（效率）和大参数（性能）方向扩展
3. **密度适中**：在最佳点附近加密，远离时稀疏

## 输出预期

完成搜索后，我们将获得：

1. **每个模型的帕累托前沿曲线**
2. **最佳效率点**（最小MAE/参数比）
3. **最佳性能点**（最小MAE，无论参数）
4. **甜点区范围**（性能接近最佳但参数合理的区间）

基于这些结果，再最终确定论文中使用的统一比较范围。
