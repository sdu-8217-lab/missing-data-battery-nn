# 统一架构搜索配置规则（参数上限 65,536 = 2^16）

## 搜索原则

1. **无下限，有上限**：从最小可行架构到 65K 参数
2. **覆盖甜点区**：确保包含初步实验发现的最佳配置
3. **密度适中**：在最佳点附近加密，远离时稀疏

---

## 各模型搜索范围

### 1. MLP（全连接网络）

**参数上限**：65,536

| 层级 | 配置范围 | 参数量上限 |
|------|---------|-----------|
| 1层 | [32] - [512] | 约8K |
| 2层 | [48,24] - [256,128] | 约50K |
| 3层 | [64,32,16] - [192,96,48] | 约40K |
| 4层 | [96,48,24,12] - [256,128,64,32] | 约65K |

**配置公式**：
```
输入维度: 16
输出维度: 1

参数量 = 16×h1 + h1 + h1×h2 + h2 + h2×h3 + h3 + ... + hn×1 + 1
       = 连接权重 + 偏置
```

**目标配置数**：
- 1层: ~20个
- 2层: ~40个
- 3层: ~35个
- 4层: ~30个
- **总计**: ~125个

---

### 2. LSTM/GRU

**参数上限**：65,536

**参数量公式**（LSTM）：
```
每层参数量 = 4 × ((input_size × hidden) + (hidden × hidden) + hidden)
总参数量 ≈ num_layers × 4 × hidden × (16 + hidden)
```

| 层级 | Hidden范围 | 最大参数量 |
|------|-----------|-----------|
| 1层 | 16 - 96 | 约46K |
| 2层 | 16 - 72 | 约45K |
| 3层 | 16 - 56 | 约43K |
| 4层 | 16 - 48 | 约40K |

**目标配置数**：
- 每层约 25-30 个配置
- **总计**: ~100个

---

### 3. CNN1D

**参数上限**：65,536

**参数量公式**：
```
Conv1D参数 = (in_channels × out_channels × kernel_size) + out_channels
总参数量 = Σ(conv_params) + fc_params
```

| 层级 | 通道配置范围 | 最大参数量 |
|------|-------------|-----------|
| 1层 | [16] - [512] | 约24K |
| 2层 | [32,16] - [256,128] | 约65K |
| 3层 | [64,32,16] - [160,80,40] | 约50K |
| 4层 | [80,40,20,10] - [192,96,48,24] | 约50K |

**目标配置数**：
- **总计**: ~120个


### 状态标记

- `pending`: 待实验
- `running`: 实验中
- `completed`: 完成
- `failed`: 失败
