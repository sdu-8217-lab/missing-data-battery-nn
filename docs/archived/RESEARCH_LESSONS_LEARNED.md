## 🎯 核心科研决策

### 1. 为什么选择MIM (Missing Indicator Method)?

**背景**: 电池数据缺失是常态,传统插补方法会引入偏差

**我们的洞察**:
```
传统思维: 缺失 = 问题 → 需要插补 → 引入误差
MIM思维: 缺失 = 信息 → 告诉网络 → 网络自适应
```

**关键验证**:
- MIM vs Mean: MAE降低 78-85%
- 高缺失率(MR≥0.7): 优势更明显
- 多种模型(MLP/LSTM/GRU/CNN)一致受益

**教训**: 不要假设"数据必须完整",不完美的数据也能有价值

---

### 2. 实验设计的关键选择

#### 选择A: 按电池划分 vs 随机划分
**决策**: 按电池划分

**原因**:
```
❌ 随机划分: 同电池的循环分散 → 数据泄漏 → 高估性能
✅ 按电池划分: 整个电池只属于一个集合 → 模拟真实场景
```

**验证**: 按电池划分的测试集性能更接近真实部署

---

#### 选择B: 混合缺失率训练
**决策**: MIM训练时混合0.0-0.9缺失率

**核心代码**:
```python
# 错误做法 (早期踩的坑)
train_dataset = BatteryDataset(X_train, missing_rate=0.5)  # 只用0.5训练

# 正确做法
for mr in [0.0, 0.1, ..., 0.9]:
    X_mr = apply_missing(X_train, mr)
    train_on(X_mr)
```

**教训**: MIM必须看遍各种缺失率才能学会适应

---

#### 选择C: 100 seeds的必要性
**决策**: 100个随机种子(42-141)

**统计依据**:
- 30 seeds: 基本统计显著
- 100 seeds: 高置信度,适合论文
- 计算成本: 可接受(3-4天GPU)

**权衡**: 统计显著性 vs 计算成本

## 💥 踩过的坑

### 坑1: MIM比Baseline差 (严重!)

**现象**:
```
MIM MAE (MR=0.9): 0.051
Baseline MAE (MR=0.9): 0.041
MIM更差?!
```

**原因**: MIM训练时只用了单一缺失率(0.5)!

**解决**: 修正为混合缺失率训练

**教训**: 当结果与预期相反时,质疑代码实现而非质疑方法

---

### 坑2: XGBoost维度不匹配

**错误**:
```
Check failed: ref->Info().num_col_ == n_features (32 vs. 16)
```

**原因**: 
- 训练集用MIMDataset(32维)
- 验证集用BatteryDataset.X(16维)

**解决**: 统一使用遍历方式获取数据

**教训**: 不同Dataset类的内部属性命名要一致

---

### 坑3: WSL2编码问题

**现象**: 中文日志乱码,R²字符报错

**原因**: Windows控制台默认GBK编码

**解决**:
1. 使用Loguru + RichHandler
2. 避免特殊Unicode字符(用R2代替R²)
3. 批处理脚本设置`chcp 65001`

**教训**: 跨平台开发要考虑编码差异

---

### 坑4: 实验中断后需从头开始

**现象**: 160配置跑了100个,中断后要从头开始

**解决**: 添加`--start-idx`参数支持恢复

```python
python run_architecture_search.py --start-idx 100
```

**教训**: 长时间实验必须支持中断恢复

---

### 坑5: 过度重构丢失功能

**现象**: 新架构没有绘图功能

**原因**: 重构时只关注核心训练,忽略了可视化

**解决**: 对照旧代码功能清单逐一验证

**教训**: 重构前列出所有功能,确保不丢失

### 3. 结果分析模板

```python
# 1. 加载结果
df = pd.read_csv('results/...csv')

# 2. 按缺失率分组统计
summary = df.groupby('missing_rate')['test_mae'].agg(['mean', 'std'])

# 3. 绘制MAE曲线
plt.plot(summary.index, summary['mean'])
plt.fill_between(summary.index, 
                 summary['mean'] - summary['std'],
                 summary['mean'] + summary['std'], 
                 alpha=0.3)

# 4. 统计检验
from scipy.stats import ttest_ind
mim_mae = df[df.method=='mim'].test_mae
mean_mae = df[df.method=='mean'].test_mae
t, p = ttest_ind(mim_mae, mean_mae)
print(f"MIM vs Mean: p={p:.4f} {'***' if p<0.001 else ''}")
```
