## 🔧 多进程加速 (重要!)

### 创建并行脚本 `run_parallel.py`
```python
import subprocess
import multiprocessing as mp

# 定义实验配置
experiments = [
    ("xjtu", "mcar", "mim", "mlp"),
    ("xjtu", "mcar", "mean", "mlp"),
    # ... 其他配置
]

def run_exp(dataset, mode, method, model):
    cmd = f"python src/main.py data={dataset} missing={mode} method={method} model={model}"
    subprocess.run(cmd, shell=True)

# 同时运行4个 (GPU内存限制)
if __name__ == "__main__":
    with mp.Pool(4) as pool:
        pool.starmap(run_exp, experiments)
```

### 运行
```bash
python run_parallel.py
```

**加速效果**: 4x (同时跑4个配置)

## 🆘 常见问题

### Q1: CUDA不可用?
```bash
# 检查驱动
nvidia-smi

# 如果显示驱动信息 → 驱动正常
# 如果报错 → 需安装NVIDIA驱动
```

### Q2: OOM (显存不足)?
```bash
# 减小batch size
python src/main.py ... training.batch_size=32  # 默认64
```

### Q3: WandB登录失败?
```bash
# 离线模式
WANDB_MODE=offline python src/main.py ...
```
