# Plotting Guide for Batch Experiments

## Quick Start

### Generate Plots from Existing Results

```bash
# From experiment directory
python plot_batch_results.py --input experiments/2C/20260203_045645/

# From aggregated CSV
python plot_batch_results.py --input experiments/2C/20260203_045645/aggregate/results_all.csv

# Custom output directory
python plot_batch_results.py --input experiments/2C/20260203_045645/ --output ./my_figures/

# Only specific metrics
python plot_batch_results.py --input experiments/2C/20260203_045645/ --metrics mae rmse
```

## Visualization Standards

### 1. Language
- **All text is in English**
- Professional academic terminology
- No Chinese characters

### 2. Color & Line Style Scheme

| Model | Color (Hex) | Baseline Style | MIM Style |

| CNN1D | #d62728 (Red) | Dashed (--) | Solid (-) |

### 3. Generated Figures

#### Metric Curves with Confidence Intervals
- `mae_curves_ci.png/pdf` - MAE vs Missing Rate
- `rmse_curves_ci.png/pdf` - RMSE vs Missing Rate
- `r2_curves_ci.png/pdf` - R² vs Missing Rate

#### Improvement Rate Analysis
- `mae_improvement_rate.png/pdf` - MIM improvement over Baseline (MAE)
- `rmse_improvement_rate.png/pdf` - MIM improvement over Baseline (RMSE)

#### Distribution Plots
- `mae_distribution.png/pdf` - MAE distribution across seeds
- `rmse_distribution.png/pdf` - RMSE distribution across seeds

#### Heatmaps
- `mae_heatmap.png/pdf` - Mean MAE heatmap

#### Seed Stability
- `seed_stability.png/pdf` - Individual seed curves with mean overlay

## Programmatic Usage

```python
from src.visualization.batch_plots import BatchExperimentPlots
import pandas as pd

# Load data
df = pd.read_csv('results_all.csv')

# Create plotter
plotter = BatchExperimentPlots(output_dir='./figures')

# Generate all plots
plotter.plot_all(df)

# Or generate specific plots
plotter.plot_metric_curves(df, 'mae', 'MAE')
plotter.plot_improvement_rate(df, 'mae')
plotter.plot_seed_stability(df)
```

## Notes

1. **Seed Stability**: Uses ALL available seeds, not limited to 10
2. **Improvement Rate**: Calculated as (Baseline - MIM) / Baseline × 100%
3. **Confidence Intervals**: 95% CI using t-distribution
4. **Formats**: Both PNG (300 DPI) and PDF (vector) are generated
