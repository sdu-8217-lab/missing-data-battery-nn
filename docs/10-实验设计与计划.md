# SOH预测缺失数据处理实验计划

## 1. 实验概述

### 1.1 实验目标

在 XJTU 电池数据集上，系统比较"仅插补" vs "插补 + 缺失指示器(MIM)"在五种常用模型架构（MLP、XGBoost、LSTM、GRU、1D-CNN）下的 SOH 预测性能和鲁棒性。

### 1.2 核心研究问题

- **RQ1**：在 XJTU 数据上，MIM 相对仅插补的实际收益如何？
- **RQ2**：不同模型架构从 MIM 中获益是否一致？
- **RQ3**：缺失率从 0.1 提高到 0.9 时，哪类模型 + MIM 组合最鲁棒？

### 1.3 实验环境

- **数据集**：XJTU 电池数据集（2C、3C、R2.5、R3、RW、Sim_satellite 六个批次）
- **开发环境**：
  - 环境管理器：Miniforge（开源免费的 Conda 环境）
  - Python：3.12.12（实验时最新稳定版本）
  - PyTorch：2.5.1（对应 Python 3.12 的最新稳定版本）
  - XGBoost：2.0+
  - 其他依赖：NumPy, Pandas, Matplotlib, Scikit-learn, SciPy, Seaborn
- **环境路径**：`D:\App\miniforge3\envs\pytorch-cpu`
- **硬件要求**：CPU（本实验使用 CPU 版本 PyTorch），内存 16GB+

## 2. 实验设计

### 2.1 特征与标签定义

#### 输入特征（16维）

| 类别 | 特征名 | 符号 |
|------|--------|------|
| **电压特征** | 电压均值 | $V_{mean}$ |
| | 电压标准差 | $V_{std}$ |
| | 电压峰度 | $V_{kurt}$ |
| | 电压偏度 | $V_{skew}$ |
| | 恒流充电电量 | $CC_Q$ |
| | 恒流充电时间 | $CC_{time}$ |
| | 电压斜率 | $V_{slope}$ |
| | 电压熵 | $V_{entropy}$ |
| **电流特征** | 电流均值 | $I_{mean}$ |
| | 电流标准差 | $I_{std}$ |
| | 电流峰度 | $I_{kurt}$ |
| | 电流偏度 | $I_{skew}$ |
| | 恒压充电电量 | $CV_Q$ |
| | 恒压充电时间 | $CV_{time}$ |
| | 电流斜率 | $I_{slope}$ |
| | 电流熵 | $I_{entropy}$ |

#### 目标标签

$$SOH = \frac{Capacity_{current}}{Capacity_{initial}}$$

### 2.2 实验因子设计

#### 因子1：缺失率（9水平）

| 水平 | 缺失率 | 备注 |
|------|--------|------|
| 1 | 0.0 | 仅用于训练MIM模型和基线模型 |
| 2 | 0.1 | 低缺失率 |
| 3 | 0.2 | 低缺失率 |
| 4 | 0.3 | 中缺失率 |
| 5 | 0.4 | 中缺失率 |
| 6 | 0.5 | 中缺失率（验证集使用） |
| 7 | 0.6 | 中高缺失率 |
| 8 | 0.7 | 高缺失率 |
| 9 | 0.8 | 高缺失率 |
| 10 | 0.9 | 极高缺失率 |

#### 因子2：模型（5水平）

| 模型 | 类型 | 输入维度（无MIM/MIM） | 序列长度 |
|------|------|----------------------|----------|
| MLP | 浅层网络 | 16 / 32 | - |
| XGBoost | 树模型 | 16 / 32 | - |
| LSTM | 时序模型 | [5,16] / [5,32] | 5 |
| GRU | 时序模型 | [5,16] / [5,32] | 5 |
| 1D-CNN | 时序模型 | [5,16] / [5,32] | 5 |

#### 因子3：输入策略（2水平）

- **Baseline**：仅插补值 $\hat{X}$
- **MIM**：插补值 + 缺失指示器 $[\hat{X} \,|\, M]$

### 2.3 实验组合

总实验组合数 = 5（模型）× 2（输入策略）× 9（缺失率，测试时）= **90组实验**

每组实验重复 **100次**（不同随机种子），总计 **9000次模型训练与评估**。

## 3. 实验步骤详解

### 阶段1：数据准备（实验前期）

#### 任务1.1：数据加载与划分
```
输入：data/XJTU data/*.csv
输出：训练集、验证集、测试集

步骤：
1. 按批次加载CSV文件（每个批次8个电池）
2. 计算SOH标签（capacity / initial_capacity）
3. 按电池划分：
   - 训练集：4个电池（50%）
   - 验证集：2个电池（25%）
   - 测试集：2个电池（25%）
4. 特征标准化（StandardScaler，在训练集上fit）
```

#### 任务1.2：序列构造（仅时序模型）
```
输入：循环级特征 [n_samples, 16]
输出：序列特征 [n_samples-seq_len+1, seq_len, 16]

步骤：
1. 对每个电池单独构造滑动窗口
2. 窗口大小 seq_len = 5
3. 目标为窗口最后一个循环的SOH
4. 注意：不同电池间不交叉构造序列
```

### 阶段2：基线模型训练（阶段1完成后）

#### 任务2.1：MLP基线
```
配置：
- 网络结构：输入(16) → 隐藏1(100) → 隐藏2(64) → 隐藏3(32) → 输出(1)
- 参数量：~10,145
- 激活函数：ReLU
- 优化器：Adam (lr=0.001)
- 训练轮数：100 epoch
- 早停：patience=15
- 批量大小：32

输出：best_model_mlp_baseline.pth
```

#### 任务2.2：XGBoost基线
```
配置：
- n_estimators: 60
- max_depth: 5
- learning_rate: 0.1
- 参数量：~7,680
- 其他：默认参数

输出：best_model_xgboost_baseline.json
```

#### 任务2.3：LSTM基线
```
配置：
- 输入维度：5×16（序列长度5，每步16维）
- LSTM层：1层，hidden_size=42
- 参数量：~9,955
- dropout: 0.2
- 输出：全连接层映射到1
- 训练配置同MLP

输出：best_model_lstm_baseline.pth
```

#### 任务2.4：GRU基线
```
配置：
- 输入维度：5×16
- GRU层：1层，hidden_size=48
- 参数量：~9,409
- 其他配置同LSTM

输出：best_model_gru_baseline.pth
```

#### 任务2.5：1D-CNN基线
```
配置：
- 输入维度：5×16
- 卷积层1：Conv1D(16→48, kernel=3, padding=1)
- 卷积层2：Conv1D(48→32, kernel=3, padding=1)
- 池化：AdaptiveAvgPool1d(1)
- 全连接：32→48→24→1
- 参数量：~9,817
- 训练配置同MLP

输出：best_model_cnn1d_baseline.pth
```

### 阶段3：MIM模型训练（阶段2完成后）

#### 任务3.1：MIM训练数据准备
```
输入：训练集 X_train [n, 16], y_train [n]
输出：扩充训练集 X_expanded [n×10, 32], y_expanded [n×10]

步骤：
1. 对于每个缺失率 mr ∈ {0.0, 0.1, ..., 0.9}：
   a. 生成缺失掩码 mask = np.random.rand(X_train.shape) > mr
   b. X_missing = X_train * mask（缺失位置置0）
   c. M = 1 - mask（缺失指示器）
   d. X_combined = concat([X_missing, M], axis=1)
2. 合并所有版本的 X_combined
3. 对应标签 y 重复100次
```

#### 任务3.2：MLP-MIM训练
```
配置：
- 输入维度：32（16特征 + 16指示器）
- 网络结构：输入(32) → 隐藏1(100) → 隐藏2(64) → 隐藏3(32) → 输出(1)
- 参数量：~11,713（比基线+1,568）
- 验证集：固定50%缺失率 + MIM格式
- 其他配置同基线

输出：best_model_mlp_mim.pth
```

#### 任务3.3：XGBoost-MIM训练
```
配置：
- 输入维度：32
- 树结构和参数量同基线（~7,680）
- 其他配置同基线

输出：best_model_xgboost_mim.json
```

#### 任务3.4-3.6：时序模型MIM训练
```
配置：
- 输入维度：5×32（序列长度5，每步32维）
- 网络结构同各基线，仅输入层不同
- LSTM-MIM：参数量~12,523（+2,568）
- GRU-MIM：参数量~11,617（+2,208）
- CNN1D-MIM：参数量~11,497（+1,680）
- 序列构造时需同时处理特征和指示器

输出：
- best_model_lstm_mim.pth
- best_model_gru_mim.pth
- best_model_cnn1d_mim.pth
```

### 阶段4：模型评估（阶段3完成后）

#### 任务4.1：单缺失率评估流程
```
对于每个模型 ∈ {MLP, XGBoost, LSTM, GRU, 1D-CNN}:
    对于每个输入策略 ∈ {Baseline, MIM}:
        对于每个缺失率 mr ∈ {0.1, 0.2, ..., 0.9}:
            对于每个随机种子 seed ∈ {100个不同的随机种子（由固定主种子生成）}:
                1. 设置随机种子
                2. 生成测试集缺失掩码（MCAR）
                3. 准备测试数据（Baseline或MIM格式）
                4. 加载对应模型
                5. 预测并计算MAE、RMSE、R²
                6. 记录结果
```

#### 任务4.2：评估指标计算
```
指标定义：
- MAE = mean(|y_pred - y_true|)
- RMSE = sqrt(mean((y_pred - y_true)²))
- R² = 1 - SS_res/SS_tot

统计分析：
- 对每个(模型, 输入策略, 缺失率)组合计算：
  - 均值（100次重复）
  - 标准差（100次重复）
  - 95%置信区间
```

#### 任务4.3：显著性检验
```
对于每个模型和缺失率：
- 配对样本t检验：比较Baseline vs MIM的MAE
- 显著性水平：α = 0.05
- 记录p值和效应量（Cohen's d）
```

### 阶段5：结果分析与可视化（阶段4完成后）

#### 任务5.1：主要结果表格
```
表格1：各模型在不同缺失率下的MAE（均值±标准差）
- 行：缺失率 0.1, 0.2, ..., 0.9
- 列：MLP-Baseline, MLP-MIM, XGBoost-Baseline, ..., 1D-CNN-MIM

表格2：MIM相对Baseline的改进百分比
- 改进率 = (MAE_baseline - MAE_mim) / MAE_baseline × 100%

表格3：显著性检验结果
- 每个(模型, 缺失率)组合的p值和显著性标记
```

#### 任务5.2：核心可视化图表
```
图表1：MAE随缺失率变化曲线（Figure 1）
- X轴：缺失率 0.1-0.9
- Y轴：MAE
- 曲线：每个模型两条线（Baseline虚线，MIM实线）
- 目的：直观展示MIM在各缺失率下的收益

图表2：模型鲁棒性对比（Figure 2）
- 展示高缺失率区（0.6-0.9）的详细对比
- 使用柱状图或箱线图

图表3：改进百分比热力图（Figure 3）
- X轴：缺失率
- Y轴：模型
- 颜色：改进百分比（绿色表示正向改进）

图表4：重复实验稳定性（Figure 4）
- 误差带图展示100次重复的标准差范围
```

### 计算量评估

以单次模型训练平均耗时估算：
- 基线模型训练：约5-30分钟/模型（GPU）
- MIM模型训练：约10-60分钟/模型（GPU，训练数据量10倍）
- 单次评估：约1-5分钟/模型

**总计算量**：
- 模型训练：10个模型 × 平均30分钟 = 约5小时（单GPU串行）
- 模型评估：9000次评估 × 平均2分钟 = 约300小时（单GPU串行）
- **建议**：阶段4使用多GPU并行或分布式计算

## 5. 风险控制

### 5.1 技术风险

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| GPU显存不足 | 中 | 高 | 减小batch_size，使用梯度累积；或改用CPU训练XGBoost |
| 训练不收敛 | 低 | 中 | 调整学习率，增加batch normalization，检查数据标准化 |
| 过拟合严重 | 中 | 中 | 增加dropout，减少模型容量，早停策略 |
| 随机种子影响过大 | 低 | 高 | 已采用100次重复，统计稳定性充足 |
| 

### 5.2 时间风险

| 风险 | 应对措施 |
|------|----------|
| 模型训练时间过长 | 使用早停，设置最大训练时间；使用更小的epoch上限 |
| 时序模型实现复杂 | 优先完成MLP和XGBoost，时序模型可作为第二阶段 |
| 结果不符合预期 | 准备备选分析角度，关注"为什么没有效果"本身也是结论 |

## 7. 预期结果

### 7.1 主效应预期

- **H1**：在中高缺失率（≥0.4）下，MIM版本显著优于Baseline
- **H2**：时序模型（LSTM/GRU/1D-CNN）从MIM中获益大于浅层模型（MLP/XGBoost）
- **H3**：缺失率越高，MIM的相对收益越大

### 7.2 交互效应预期

- 1D-CNN可能在极高缺失率（0.8-0.9）下表现最佳
- XGBoost的MIM收益可能不如神经网络显著（树模型对稀疏特征的处理能力差异）

### 7.3 最小可检测效应

- 以MAE为指标，假设标准差为0.02
- 100次重复，配对t检验，α=0.05，power=0.8
- 可检测的最小差异：约0.005 MAE（统计功效显著提升）
