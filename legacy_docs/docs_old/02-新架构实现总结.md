# 新实验架构实现总结

## 完成的工作

### 1. 核心架构组件

#### 检查点管理 (`src/experiments/checkpoint.py`)
- 支持实验状态保存和恢复
- 记录已完成/失败的种子
- 支持断点续跑

#### 小实验运行器 (`src/experiments/single_experiment.py`)
- 固定随机种子的完整实验
- 训练所有10种模型配置
- 区分Baseline和MIM训练策略
- 即时保存结果和图表

#### 大实验运行器 (`src/experiments/batch_experiment.py`)
- 批量管理小实验执行
- 支持中断恢复 (`--resume`)
- 定期保存聚合结果
- 自动调用统计绘图

### 2. 训练策略实现

#### Baseline训练（不带缺失指示器）
```python
# 只用完整数据训练1次
train_data = BatteryDataset(X_train, y_train, missing_rate=0.0, use_mim=False)
```

#### MIM训练（带缺失指示器）
```python
# 复制10份，分别施加不同缺失率
for mr in [0.0, 0.1, ..., 0.9]:
    X_copy = apply_missing(X_train, missing_rate=mr)
    X_with_indicator = concat([X_copy, missing_indicators])
    train_list.append(X_with_indicator)

# 拼接成大训练集
train_data = concat(train_list)  # 10×原大小
```

### 3. 独立绘图脚本

#### 小实验绘图 (`src/visualization/single_plots.py`)
- MAE/RMSE/R2随缺失率变化曲线
- 模型对比图
- MIM改进幅度图

#### 大实验绘图 (`src/visualization/batch_plots.py`)
- MAE分布小提琴图/箱线图
- 带置信区间的曲线
- 改进幅度分布
- 统计显著性热图
- 种子稳定性分析

#### 独立绘图脚本
- `plot_single.py`: 为单个小实验绘图
- `plot_batch.py`: 为大实验绘制统计图

### 4. 用户接口脚本

| 脚本 | 用途 | 示例 |
|------|------|------|
| `run_batch.py` | 运行大实验 | `python run_batch.py --n_repeats 100` |
| `run_single.py` | 运行单个小实验 | `python run_single.py --seed 42` |
| `plot_batch.py` | 批量绘图 | `python plot_batch.py --input experiments/3C/...` |
| `plot_single.py` | 单实验绘图 | `python plot_single.py --input seed_42/results.csv` |
| `check_status.py` | 检查状态 | `python check_status.py --experiment_dir ...` |

## 目录结构

```
experiments/{batch}/{timestamp}/
├── checkpoint.json              # 检查点
├── logs/batch.log              # 主日志
├── seed_42/                    # 小实验1
│   ├── seed_42.log
│   ├── results.csv            # 结果数据
│   ├── figures/               # 5张图表
│   └── models/                # 10个模型
├── seed_43/                    # 小实验2
├── ...
└── aggregate/                  # 统计结果
    ├── results_all.csv        # 合并数据
    └── figures/               # 6张统计图表
```

## 关键特性

### 1. 容错与恢复
```bash
# 中断后继续
python run_batch.py --n_repeats 100 --resume

# 检查进度
python check_status.py --experiment_dir experiments/3C/...
```

### 2. 独立绘图
```bash
# 大实验中断后手动绘图
python plot_batch.py --input experiments/3C/20240203_120000

# 为特定种子绘图
python plot_single.py --input experiments/3C/.../seed_42/results.csv
```

### 3. 单独调试
```bash
# 只运行特定种子
python run_single.py --seed 100 --epochs 50
```

## 与旧架构对比

| 特性 | 旧架构 | 新架构 |
|------|--------|--------|
| 实验结构 | 单层循环 | 分层（大/小实验） |
| 保存时机 | 最后统一保存 | 每小实验立即保存 |
| 中断恢复 | ❌ 不支持 | ✅ 支持 |
| 独立绘图 | ❌ 不支持 | ✅ 支持 |
| 单种子调试 | ❌ 不支持 | ✅ 支持 |
| 统计图表 | ❌ 无 | ✅ 6种统计图 |
| 容错隔离 | ❌ 无 | ✅ 单种子失败不影响其他 |

## 待测试项目

在正式运行完整实验前，建议进行以下测试：

1. **小规模测试**: 运行2个种子验证架构
