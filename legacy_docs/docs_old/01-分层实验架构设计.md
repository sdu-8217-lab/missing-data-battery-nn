# 实验架构设计文档

## 1. 架构概述

实验采用**分层架构**：
- **小实验 (SingleExperiment)**：单次完整实验，固定随机种子
- **大实验 (BatchExperiment)**：多次小实验的批量执行，不同随机种子

```
BatchExperiment (大实验)
├── SingleExperiment_1 (seed=42)
├── SingleExperiment_2 (seed=43)
├── ...
└── SingleExperiment_100 (seed=141)
    
SingleExperiment (小实验)
├── MLP-Baseline
├── MLP-MIM
├── LSTM-Baseline
├── LSTM-MIM
├── ...
└── XGBoost-MIM
```

## 2. 小实验 (Single Experiment)

### 2.1 职责
- 使用固定随机种子
- 训练所有模型配置（10种）
- 评估所有缺失率（9种）
- 生成该次实验的图表
- **立即保存结果**，不等待其他种子

### 2.2 训练策略

#### Baseline模型（不带缺失指示器）
```
输入: 完整训练集 (X_train, y_train)
处理: 无缺失处理
训练: 标准训练流程
输出: 训练好的模型
```

#### MIM模型（带缺失指示器）
```
输入: 完整训练集 (X_train, y_train)
处理:
  1. 复制训练集为10份 (copy_0 ~ copy_9)
  2. copy_0: 保持完整 (missing_rate=0.0)
  3. copy_1~9: 分别施加 missing_rate=[0.1, 0.2, ..., 0.9]
  4. 拼接所有副本形成大训练集 (10×原大小)
训练: 在大训练集上训练
输出: 训练好的模型
```

### 2.3 输出结构
```
experiments/{batch_name}/{timestamp}/
├── seeds/                          # 各小实验结果
│   ├── seed_42/
│   │   ├── results.csv            # 该种子的所有结果
│   │   ├── figures/               # 该种子的图表
│   │   └── models/                # 该种子的模型
│   ├── seed_43/
│   └── ...
├── aggregate/                     # 大实验统计结果
│   ├── results_all.csv           # 所有种子合并结果
│   └── figures/                   # 统计性图表
└── logs/
```

## 3. 大实验 (Batch Experiment)

### 3.1 职责
- 管理100次小实验的执行
- 支持中断恢复（断点续跑）
- 调用统计绘图脚本
- 生成跨种子的统计性图表

### 3.2 容错机制
```python
# 检查已完成的种子
completed_seeds = check_completed_seeds(experiment_dir)

# 跳过已完成的，只运行未完成的
for seed in all_seeds:
    if seed in completed_seeds:
        continue  # 跳过
    run_single_experiment(seed)
```

### 3.3 统计性图表
- 各模型MAE分布（箱线图/小提琴图）
- 缺失率-MAE曲线的置信区间
- 模型对比的显著性检验
- 概率密度分布图

## 4. 独立绘图脚本

### 4.1 小实验绘图 (`plot_single_experiment.py`)
```bash
# 为单个小实验绘图
python plot_single.py --seed 42 --input results.csv --output figures/
```

### 4.2 大实验绘图 (`plot_batch_experiment.py`)
```bash
# 为所有完成的小实验绘制统计图
python plot_batch.py --input seeds/ --output aggregate/figures/
```

### 4.3 手动恢复
```bash
# 大实验中断后，手动绘制已有结果的统计图
python plot_batch.py --input experiments/3C/{timestamp}/seeds/
```

## 5. 代码结构

```
src/
├── experiments/
│   ├── __init__.py
│   ├── single_experiment.py      # 小实验运行器
│   ├── batch_experiment.py       # 大实验运行器
│   └── checkpoint.py             # 断点管理
├── visualization/
│   ├── single_plots.py           # 小实验绘图
│   └── batch_plots.py            # 大实验统计绘图
└── scripts/
    ├── run_single.py             # 运行单个小实验
    ├── run_batch.py              # 运行大实验
    ├── plot_single.py            # 单实验绘图脚本
    └── plot_batch.py             # 批量绘图脚本
```

## 6. 工作流程

### 6.1 正常流程
```
1. 用户调用 run_batch.py --n_repeats 100
2. BatchExperiment 循环 100 个种子
3. 对每个种子调用 SingleExperiment
4. SingleExperiment:
   - 训练所有模型
   - 评估所有缺失率
   - 保存结果到 seeds/seed_{n}/
   - 调用 plot_single.py 生成图表
5. 所有种子完成后，BatchExperiment 调用 plot_batch.py
6. 生成统计性图表保存到 aggregate/
```

### 6.2 中断恢复流程
```
1. 用户重新调用 run_batch.py --n_repeats 100 --resume
2. BatchExperiment 检查已完成的种子
3. 跳过已完成的，继续未完成的
4. 完成后调用 plot_batch.py 更新统计图
```

### 6.3 手动绘图流程
```
1. 大实验意外中断（完成67/100）
2. 用户调用 plot_batch.py --input experiments/3C/{timestamp}/seeds/
3. 脚本读取67个已完成的结果
4. 生成基于67次实验的统计图
```

## 8. 关键设计决策

### 8.1 为什么分层？
- **容错**：单个小实验失败不影响其他种子
- **并行**：未来可支持多进程并行运行小实验
- **灵活**：可单独运行某个种子进行调试

### 8.2 为什么独立绘图？
- **可恢复**：中断后可手动生成统计图
- **迭代**：可修改绘图代码重新生成图表
- **解耦**：绘图与实验执行解耦

### 8.3 为什么MIM要拼接数据？
- 让模型在一次训练中看到各种缺失率的数据
- 模型学习识别缺失模式并自适应
- 相比Baseline，显著提升高缺失率场景的性能

## 9. 使用示例

### 9.1 运行完整大实验
```bash
python run_batch.py --batch 3C --n_repeats 100 --epochs 50
```

### 9.2 中断恢复
```bash
python run_batch.py --batch 3C --n_repeats 100 --resume
```

### 9.3 运行单个小实验（调试）
```bash
python run_single.py --batch 3C --seed 42 --epochs 50
```

### 9.4 手动生成统计图
```bash
# 大实验中断后，基于已完成结果绘图
python plot_batch.py --input experiments/3C/20240203_120000/seeds/

# 更新特定种子的图
python plot_single.py --input experiments/3C/20240203_120000/seeds/seed_42/results.csv
```
