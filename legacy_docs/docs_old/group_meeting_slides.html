论文方法动机与 CDE 基础

为什么用 Neural CDE 处理电池缺失数据？

Motivation
核心动机
电池容量退化是连续动态过程。传统 RNN/Transformer 将数据离散化，难以自然处理非规则采样与缺失。
Background
Neural ODE
用神经网络参数化隐藏状态演化：dh/dt = f(h(t), t)。适合平滑连续过程，但难以直接利用多变量输入。
Background
Neural CDE
用控制路径 X(t) 驱动隐藏状态：h(t) = h(0) + ∫ f(h(s)) dX(s)。V/I/T 轨迹天然可作为控制路径。
Missingness
CDE 如何处理缺失
先用插值构造连续路径 X(t)，缺失处由插值填补；ODE solver 可在任意时刻评估，无需固定时间步。
Paper Claims
论文的宣称
BatteryCDE 声称实现：(1) 长期容量预测；(2) 不规则采样与缺失数据；(3) 跨电池迁移。
Our Question
我们的关注点
"天然处理缺失"是否成立？CDE + 双重注意力在电池 SOH 上是否确实优于 LSTM/Transformer？

BatteryCDE 结构与实验设定

三重 CDE + 双重注意力 + NASA 实验配置

Architecture
feature-wise CDE
每个特征通道独立运行 CDE，输出 a_feat(t) ∈ (0,1)，作为特征注意力权重。
Architecture
cycle-wise CDE
输出 a_cycle(t) ∈ (0,1)，作为循环/时间步注意力权重，强调关键退化阶段。
Architecture
learning CDE
以注意力加权后的路径 Y(t) 为输入，积分得到最终隐藏表示，经 readout 输出容量。
Data
NASA 数据设定
充电段 V/I/T 轨迹重采样为 30 步；history_len=3；horizon=50；容量按训练集最大容量归一化。
Missingness
缺失实验设定
在原始充电轨迹上施加 random 随机缺失与 block 连续块缺失，缺失率 30% / 50%。
Transfer
迁移实验设定
NASA 电池间跨电池迁移：B5/B6 训练→B7/B18 测试，以及 B7/B18 训练→B5/B6 测试。

关键发现

单 seed 复现的初步结论

BatteryCDE 未显著优于 Transformer
论文宣称的 CDE 优越性在本设置下未复现；Transformer 在 NASA 基线上 MAE 最低（0.033 vs 0.037）。
单 seed 结果极不稳定
horizon 与 missing 实验均出现反直觉排序（h=80 最优而 h=50 最差；random30 优于 clean）。
R² 为负是普遍现象
所有实验中 R² < 0，说明模型预测不如简单用训练集均值。任务设置、数据划分或容量缩放方式需优先诊断。
连续块缺失反而更稳定
block30/block50 的 MAE 低于 clean 与 random 缺失。可能与 spline 插值对结构化时间缺失更友好有关。
核心判断：基于当前单 seed 结果，BatteryCDE 的 claim 在本设置下不稳健；需通过多 seed 重复与任务诊断后再下结论。

下一步与对我们研究课题的启示

从 BatteryCDE 复现到本课题的方法论升级

短期行动
  • 多 seed 重复，量化单 seed 波动性与统计显著性
  • 诊断负 R² 根源：容量缩放、数据划分、horizon 定义
  • 将 BatteryCDE 纳入项目主方法矩阵，与 GroupMIM/GNN 公平对比
长期路线
  • 启动 Physics-augmented Neural CDE（Toom et al., JPS 2026）复现
  • 探索 CDE + 结构感知缺失处理（GroupMIM/GNN）的融合架构
  • 构建跨数据集、多缺失机制的统一 benchmark
对我们研究课题的帮助
  • 第三条缺失处理路线：在 MIM/GroupMIM/GNN 之外，CDE 提供了"连续时间插值 + 端到端估计"的新范式，可弥补当前项目离散时间建模的不足。
  • 实验设计参考：BatteryCDE 的 horizon、missing、transfer 三维度评估为我们的 benchmark 设计提供了可直接借鉴的框架。
  • 批判性方法观：复现失败提醒我们，对论文 claim 必须保持审慎——优越性的验证需要多 seed、多数据集、强基线与统计检验。
  • 物理约束融合：PA-NCDE 将单调性约束与等效电路知识融入连续时间模型，与本课题"物理信息融合"方向高度契合。
